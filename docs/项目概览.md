# 项目概览

Local Agent Runtime Console 是面向中国用户的本地优先 AI Agent 运行观测台。它将散落在本机 Provider 中的任务、运行、事件和输出整理为统一视图，并允许用户从面板发起可深度观测的任务。

## 目标用户

- 使用 Codex CLI 或 Codex 桌面客户端完成开发任务的个人开发者。
- 需要同时观察多个任务、父子任务和长时间运行过程的用户。
- 希望运行数据留在本机、不依赖外部数据库或云端账号体系的用户。

## 产品目标

1. 提供可信的全局任务看板，减少在多个任务之间切换的成本。
2. 对受管任务提供事件、时间线、输出、Token 和工具调用的深度观测。
3. 以 Provider 抽象承载未来的其他 AI Agent Runtime，而不污染通用领域模型。
4. 提供 Windows、macOS 和 Linux 可直接安装的本地桌面应用。
5. 默认使用嵌入式 SQLite，使用户无需安装或维护外部数据库。

## 当前范围

- 当前仅实现 `CodexProvider`。
- Codex CLI 由用户自行安装和登录，观测台不读取账号密码。
- 数据默认保存在用户电脑上的 SQLite 数据库中。
- GitHub 是主仓库、Issue 和 Release 渠道；Gitee 是同步镜像。
- 中文界面和中文文档优先，暂不承诺完整英文界面。

## 非目标

- 不替代 Codex CLI、Codex 客户端或其官方账号与计费页面。
- 不提供多用户、团队权限、远程控制或云端任务托管。
- 不把本机提示词、输出、工作目录或命令上传到项目维护者的服务器。
- 不根据标题、时间或 UI 状态猜测任务关系和运行状态。
- 不承诺读取 Provider 没有公开或持久化的内部推理过程。

## 当前成熟度

`0.1.0` 已完成通用契约、Web、Local API、Codex 接入、SQLite 持久化、Electron 封装和跨平台构建流水线基线。Windows 目录包已完成本机启动验证；签名、应用图标、校验值、macOS/Linux 真机安装和升级策略仍是首个公开 Release 的门槛。
