# 功能目录

本页同时记录产品能力与观测限制。`0.1.0` 为首个开源开发基线，Release 前仍可能调整安装与升级行为。

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| Provider 抽象 | 已有原型 | 统一任务、运行、事件、输出和指标契约。 |
| `CodexProvider` | 已有原型 | 通过 `codex app-server` 发现任务、发起运行和接收事件。 |
| 全局任务看板 | 已有原型 | 搜索、筛选、分页并查看本机 Codex 任务。 |
| 父子任务关系 | 已有原型 | 仅展示 Provider 事件能够证明的关系。 |
| 受管任务 | 已有原型 | 从面板发起任务并记录运行生命周期。 |
| 执行时间线 | 已有原型 | 按事件顺序展示输入、推理、工具调用、输出与完成状态。 |
| 事件日志 | 已有原型 | 默认展示关键事件，可切换完整事件并查看详情。 |
| 输出预览 | 已有原型 | 展示流式快照或最终 Markdown 输出。 |
| Token 与额度 | 已有原型 | 展示本机可观测数据，不作为官方账单。 |
| 本机使用分析 | 已有原型 | 按来源、模型和 Skill 聚合本机记录。 |
| SQLite 持久化 | 已完成基线 | 使用 Node 内置 SQLite，提供版本化迁移、事务和启动恢复。 |
| 本地桌面应用 | 已完成基线 | Electron 管理 Local API、窗口和系统数据目录。 |
| 跨平台构建 | 已完成基线 | GitHub Actions 构建 Windows、macOS、Linux 安装包草稿。 |
| 自动更新 | 规划中 | 必须支持用户知情、签名校验和关闭更新。 |
| 其他 Provider | 未开始 | 在不修改通用领域契约的前提下逐个接入。 |

## 状态语义

任务状态分为业务状态与观测状态：

- 业务状态：`queued`、`running`、`waiting`、`completed`、`failed`、`interrupted`。
- 观测状态：`stale`、`disconnected`、`unknown`，表示信息不足或连接异常，不等价于任务失败。
- 聚合筛选：活跃任务、异常任务等只用于看板筛选，不是新的持久化状态。

状态映射以 Provider 事实为准，不能用客户端窗口是否开启、列表排序或最近更新时间单独判定。

## 数据可见性

| 数据 | 全局任务 | 受管任务 |
| --- | --- | --- |
| 标题、目录、最近活动 | Provider 可见时支持 | 支持 |
| 当前状态 | 可能不完整 | 支持 |
| 细粒度事件 | 仅限本机已有记录 | 支持 |
| 实时输出 | 通常不可恢复 | 支持 |
| 中断运行 | 不保证 | 运行标识有效时支持 |

Provider 能力不足时，界面应明确展示“不可见”或“未知”，不得用默认值伪装完整数据。
