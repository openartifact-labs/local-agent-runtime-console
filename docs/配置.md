# 配置说明

项目坚持零外部数据库依赖。用户不需要安装数据库服务；开源桌面版只使用本机 SQLite。

## Local API

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `API_HOST` | `127.0.0.1` | Local API 监听地址。为保护本机数据，不应改为公网地址。 |
| `API_PORT` | `4318` | Local API 开发端口。 |
| `WEB_ORIGIN` | `http://127.0.0.1:4317` | 开发环境允许的 Web Origin。 |
| `LOG_LEVEL` | `info` | 日志级别，例如 `debug`、`info`、`warn`、`error`。 |
| `DATABASE_PATH` | `.runtime/data/runtime-console.sqlite` | 开发环境 SQLite 路径；桌面版使用系统应用数据目录。 |

桌面应用不得要求用户手动填写数据库地址、用户名或密码。SQLite 文件不应提交到 Git。

## Codex Provider

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `CODEX_BIN` | `codex` | 用户自行安装的 Codex CLI 命令或可执行文件路径。 |
| `CODEX_REQUEST_TIMEOUT_MS` | `30000` | 单次 App Server 请求超时。超时不代表远端动作一定未发生。 |
| `CODEX_RECONNECT_BASE_DELAY_MS` | `500` | 断线后的首次重连延时。 |
| `CODEX_RECONNECT_MAX_DELAY_MS` | `30000` | 指数退避的最大重连延时。 |
| `CODEX_SYNC_INTERVAL_MS` | `5000` | 全局任务同步间隔。 |
| `CODEX_STALE_AFTER_MS` | `180000` | 运行长期无新记录后转为失联观测状态的阈值。 |
| `CODEX_LIST_PAGE_SIZE` | `100` | 单次任务列表读取条数。 |
| `CODEX_LIST_MAX_PAGES` | `100` | 单轮同步最多读取页数。 |

本项目不提供 `CODEX_TOKEN`、账号密码或 Cookie 配置。Codex 登录完全由用户在 Codex CLI 中完成。

## Web

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `VITE_API_BASE_URL` | `/api` | Web 使用的 REST 与 SSE 公共前缀。桌面生产包使用同源 Local API。 |

## 数据目录

开发模式可以将数据放在仓库内 Git 忽略的 `.runtime/`。正式桌面版应使用系统标准应用数据目录：

- Windows：用户级应用数据目录。
- macOS：用户 `Application Support` 目录。
- Linux：遵循 XDG Base Directory 规范。

具体目录由桌面运行时确定，界面应提供“打开数据目录”和“备份数据库”入口。不要在文档、Issue 或日志中公开真实数据目录中的用户名和任务内容。

## 环境文件

`.env.example` 只能包含无秘密的默认模板。本机覆盖配置使用 `.env` 或对应开发环境文件，并保持 Git 忽略。提交前应检查其中不包含凭据、个人路径和真实任务数据。
